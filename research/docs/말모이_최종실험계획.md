### E1. 4조건 전량 재실행 → 배치·분모 통일 [1~2일]
- **300건 × 4조건 전부 재실행** (NERinject만 다시 돌리면 조건 간 비교가 구·신 배치 혼합이 됨 — 배치 불균질을 조건 내에서 조건 간으로 옮기는 꼴. 1,200콜이면 비용 미미)
- timeout 60→180초, 각 호출의 **시점·모델 별칭·재시도 횟수를 jsonl에 기록** (사후 배치 구분 가능하게)
- 성공 시: 전 조건 n=300 기사/527 엔티티로 통일. **전 지표 재계산** — ETS, 교차분류표(4-3/4-4/4-5), McNemar, BLEU 전부. 표 4-2의 n 열 단일화
- 예상 시나리오: 탈락분이 장문·고난도라 ETS 하락 가능(0.86~0.88대 추정). **하락해도 그대로 보고** — 논문의 셀링포인트가 "평가의 정직성"이므로 일관성이 오히려 자산. NERinject 70:0 구조(악화 0)는 장문에서도 유지될 가능성이 높아 결론 방향은 불변
- 재실행 후에도 실패하는 건이 있으면: 해당 건만 "장문 API 한계로 인한 결측(MNAR), 결과가 낙관 편향될 수 있음"을 정직하게 각주 처리

### E2. 통계 패키지 완성 [1일, 대부분 완료]
- McNemar 정확검정 표(이미 계산됨)를 E1 재실행 데이터로 갱신 후 본문 표로 승격
  - 특히 **NERinject vs Few-shot 70:0 (p=1.7e-21)** — 현재 논문에 없는 최강 근거, 반드시 수록
- BLEU(c) 조건 간 차이에 paired bootstrap resampling (sacrebleu `--paired-bs`, n=1,000) 추가
- Few-shot ETS 하락은 **중립 결과로 재서술**: "Few-shot은 문체를 개선하면서 인명 정확도를 유의하게 훼손하지 않는다(McNemar p=0.345)" — 트레이드오프 서사 철회

### E3. 분모 고정 순환성 대조 실험 — 논문의 심장 [1주]
**설계 원칙: 분모(엔티티 집합)를 고정하고 정답 독음 소스만 교체한다.** 분모가 조건마다 다르면 점수 차이가 순환성 효과인지 집합 차이인지 분리 불가 — 3단 하락 곡선 대신 성립하는 2단 대조로 간다.

| 지표 | 분모 (고정) | 정답 독음 소스 | 순환성 |
|------|------------|---------------|--------|
| ETS-KB | SJW HTML 527 엔티티 | person_master + hanja (= 주입 소스) | 부분 순환 (현재 ETS) |
| ETS-REF | SJW HTML 527 엔티티 (동일) | 국역 reference에 실제 쓰인 표기 | 순환 없음 |
| (참고) NER Recall | SillokBERT 추출 집합 | KB | 완전 순환 = 1.000 — 집합이 달라 엄밀 비교 불가, 참고 수치로만 언급 |

**ETS-KB − ETS-REF의 차이가 곧 순수한 순환 효과** — 논문이 주장할 바로 그 숫자.

**ETS-REF 구축 절차** (한국어 NER 모델 사용 금지 — 현대어 학습 모델은 조선 인명·관직 구분 불가, 노이즈 유입):
1. 527개 엔티티 각각에 대해 후보 독음(KB값 + hanja 음독 + 성씨 앵커 변형)을 reference에서 반자동 매칭
2. 팀 내부 2인이 전수 확인 (한글 대조 작업, 2인 하루 분량). 2인 일치율(Cohen's κ) 보고
3. **REF-부재 예외 규칙**: reference가 인명을 직함으로 대체·생략한 엔티티는 별도 카테고리(REF-부재)로 집계하고 개수 명시. ETS-REF는 **부재 제외 분모 / 전체 분모(부재=오답) 두 버전 병기** — 어느 계산으로도 결론이 유지됨을 보여 분모 조작 의심을 차단
4. **KB≠REF 불일치 사례 분해 (검수와 동시 수행, 추가 비용 0)**: 불일치 케이스 전수를 "진짜 오독 주입 / 정당한 표기 변이(자·호·시호, 번역 관행 차이) / 판단 불가"로 분류하고, **순수 순환 성분이 갭의 몇 %인지 보고**. 갭이 클수록 리뷰어의 첫 질문은 "진짜야?"이며, 분해 없는 큰 갭은 "순환 효과"가 아니라 "채점 엄격도 차이"로 반박당함 — 이 분해가 헤드라인의 방탄복
5. 4개 조건 전부 ETS-REF 채점
- 기대 결과: ETS-KB > ETS-REF면 순환 부풀림의 최초 정량화. ETS-KB ≈ ETS-REF여도 "부분 순환의 실질 왜곡은 제한적"이라는 발견으로 성립 — 어느 쪽이든 결과가 논문이 됨

### E3b. ETS 채점 프로토콜 강화 [2일] — **필수** (선행이 이미 구멍을 지적함)
KoBE(Gekhman et al., Findings of EMNLP 2020)가 recall 단독 지표의 과잉 생성 부풀림을 진단하고 Entity Count Penalty(ECP)로 해결했고, Alam et al.(2021, arXiv 2106.11891)이 "용어를 출력 끝에 갖다 붙인 cheated 시스템"을 단순 존재 채점이 못 잡음을 실증했다. 현행 `정답명 in hypothesis` 채점은 두 선행이 지목한 구멍 그대로다.

**최종 채점 프로토콜을 하나로 통합** (지표 증식 금지 — 리뷰어는 지표 동물원을 싫어함):
- recall + **ECP류 카운트 페널티**(출력 인명 수/정답 인명 수 비율 페널티) + **위치 검증**(reference에서 해당 인명 주변 ±w 내용어 윈도와 hypothesis 등장 위치 윈도의 겹침 확인)을 결합한 **ETS-F1 단일 프로토콜** 확정
- FP 조작적 정의는 유지: 정답지 외 KB 사전 등재 인명 등장 (사전 매칭, 결정론적). 한계(사전 외 오삽입 미포착) 한 줄 명시
- **분모 고정 대조(E3)는 이 단일 프로토콜 위에서 수행** — 위계: 지표 강화 = due diligence, 출처 스왑 대조 = 기여

**앵무새 데모 (반나절)**: 주입 인명 전부를 번역문 말미에 이어붙인 적대적 출력 구성 → naive ETS는 만점, 강화판 ETS-F1은 탐지함을 표 하나로 시연. Alam et al.의 cheated-system 실험의 도메인 재현이자, "선행을 알고 개선했다"는 신호 + JOCCH가 요구하는 수치 너머의 분석

### E4. 다중모델 미니 ablation [3~5일, API 비용 소액]
- **대형 1~2종 + 소형 1~2종 의도적 혼합**: 대형은 GPT-4 계열 또는 DeepSeek-v3, 소형은 Qwen3-4B·Phi4-mini (둘 다 baseline 3,000건 완주 이력 있어 추가 비용 적음)
- 조건 3개만: Baseline / Few-shot / NERinject (NERfix 생략 — 규칙 기반이라 모델 무관)
- 평가셋 300건 전체 × 3조건 × 3~4모델, ETS-KB·ETS-REF와 BLEU(c) 산출
- 목적 1: "KB 주입 효과와 순환 착시가 모델 불문 재현되는가"
- 목적 2 (신규 발견 축): **모델 규모에 따른 KB 주입 효과의 변화** — NERinject는 지시 이행 능력 의존 기법이므로 소형에서 효과가 죽는지/사는지가 독립적 발견. "KB 주입은 지시 이행 능력이 전제되어야 작동한다"류의 실무 결론 가능. JOCCH가 요구하는 "수치 너머의 모델 특성 심층 분석"에 정확히 해당

### E5. 무필터 검증 실험 [2일, **필수**]
- 필터(`_gemma_bleu>=20`) 미적용 무작위 300건 추출 (새 seed 명시)
- **Baseline / Few-shot / NERinject 3조건** 실행 (2조건이면 Few-shot 기여와 NERinject 증분이 섞여 분리 불가)
- 목적: 평가셋 편향(E) 공격의 완전 무력화 — `make_eval_set.py` 한 줄만 봐도 드러나는 사실이라 "Δ는 유지된다"는 논리 방어만으로는 약함. 실측 하나로 종결
- §4-1 서술 분리와 세트: 모델 선정 근거는 무필터 31.92(n=3,000)로 정정

### 인간평가 대체 설계 (섭외 최소화 반영)
- 정식 MQM/ESA **생략**. 대신:
  - (a) ETS-C 검수(위 E3-3단계)가 인명 정확도의 인간 검증을 겸함
  - (b) 문체 평가 (블라인드 필수 — 저자 자평 구조라 이거 없으면 없느니만 못함): 조건 라벨 완전 제거 + 번역문 순서 무작위화, 팀 2인 독립 수행 후 Cohen's κ 보고, 평가자가 저자임을 논문에 명시. 50건 reference 대비 비교(3점 척도), "예비적 정성 평가"로 위치
  - (c) 정성 분석: "둘 다 오답" 구간(E1 재실행 후 갱신)의 오류 유형화 — JOCCH가 요구하는 "수치 너머의 심층 분석" 충족
- 워크숍/JOCCH 리뷰에서 정식 인간평가 요구가 나오면 리비전 단계에서 확장 (교신저자 경유)

- [ ] GuNER 2023·EvaHan 2025를 **긍정적 동기 프레이밍**으로 인용: "전문가 골드가 존재하는 고전 중국어 NER 평가에서는 순환이 발생하지 않는다(수작업 어노테이션 비용을 명시적으로 전제). 순환은 골드가 희소해 KB로 정답지를 대체하는 저자원 도메인에서 비로소 발생하며, 본 연구의 설정이 정확히 그 조건이다" — 부재 증명이 아니라 문제 발생 조건의 실증으로 전환

JOCCH 정체성 맞춤 (전부 글쓰기 — 비용 대비 승률 효과 최대 구간):
- [ ] **문화유산 임팩트 섹션 신설**: 완역 추산 2062년·ITKC의 2035년 단축 사업 맥락 위에 "번역가 검토 전 초안 도구" 시나리오 서술 + **resource-shared loop의 실무 지침 번역**: "KB 주입형 번역을 도입하는 아카이브 기관은 평가 정답지를 주입 자원과 분리 구축해야 한다" — 타 기관이 가져다 쓸 수 있는 절차 체크리스트 형태로
- [ ] **정성 분석을 역사 서사로**: 오류 사례 2~3건을 역사적 실체까지 서술 (예: 張維[1587–1638, 인조반정 공신]의 오독이 동시대 인물 혼동으로 이어져 사료 해석을 어떻게 왜곡하는가). 숫자 뒤의 인물을 보여주는 게 인문학 리뷰어 설득 포인트
- [ ] **국제 독자용 배경 장치**: 한자 다독음 문제와 한-서구 entity 번역의 차이를 그림 1개 + 예시 글로스로 서론 초반에 배치 — 리뷰어가 문제 자체를 이해 못 하면 "so what"으로 죽음, 학부생 논문 최다 사망 지점
- [ ] **저널 내부 대화 접속**: JOCCH 기게재 논문(논어 LLM 번역 10.1145/3797271, SikuGPT, ArcheoBERTje)을 related work에서 호명 — 에디터의 데스크 단계 스코프 판단에 작동
- [ ] 커버레터: 위 문단 + HERITAGE/H2KE와의 차별점(NER→번역 프롬프트 주입 결합 + 평가 방법론) 1문단

## 4. 작업 순서 및 행정 체크리스트

## 5. 분기 기준 (사전 결정)

- **E1 재실행 후 ETS가 0.85 밑으로 크게 하락** → 결론 강도를 낮추되 노선 유지. "장문 구간이 KB 주입의 실질 한계"라는 발견으로 discussion 강화
- **E3에서 ETS-REF ≈ ETS-KB** (순환 왜곡이 작음) → "부분 순환의 실질 영향은 제한적" 프레임으로 전환, 여전히 최초 정량화라는 기여 유지
- **E3에서 갭이 큼** (예: ETS-REF가 0.85 밑) → "경고 논문"으로 격상 가능하나 **불일치 분해 분석(E3-4단계) 없이는 헤드라인화 금지** — 순수 순환 성분 비율을 먼저 확정하고, 그 수치를 초록·기여에 배치
- **E3가 3주를 초과** → arXiv v1을 E1+E2 범위로 선공개하고 E3/E3b는 v2에 반영. arXiv 지연은 옳지만 무기한 지연은 더 큰 리스크 — 병역 일정은 되돌릴 수 없는 고정 마감
- **워크숍 리뷰가 방법론 신규성 인정** → JOCCH 완전판 강행 / **"기여 미약" 평** → 코퍼스·자원 각도 강화해 LRE로 선회 (단, 라이선스 확인 선행)
- **JOCCH desk reject** → LRE → IEEE Access 순 폴백
- **지도교수 섭외 실패** → 팀 단독 투고 강행, 입대 전 리비전 대응 계획을 팀원에게 위임 문서화
