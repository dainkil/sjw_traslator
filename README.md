# 승정원일기 번역 서빙 시스템

> **2062년으로 추산된 《승정원일기》 완역 시점을, 얼마의 비용으로 언제까지 당길 수 있는가.**

승정원일기(총 2억 4,250만 자)의 국역 완료율은 37.4%이며, 현행 속도로는 완역까지 2062년이 걸린다.
이 프로젝트는 [선행 연구](research/README.md)(지식 주입형 번역 파이프라인: SillokBERT-NER + 인물 KB 링킹 + 프롬프트 증강 + LLM)를 **운영 가능한 번역 서빙 시스템**으로 전환하고, 잔여 약 1억 5천만 자 완역의 비용/시간을 실측 기반으로 산출한다.

## 헤드라인 (마일스톤별 실측으로 교체 중)

| 항목 | 수치 | 상태 |
|---|---|---|
| 잔여 코퍼스 완역 | 유료면 **약 $842 ≈ 118만 원 / 0.9일** — 무료 quota로는 **173년** (단일 모델 RPD 20 실측) | 토큰·지연 실측 반영 → M2 배치 실측 |
| **전체 지연 중 외부 LLM 비중** | **p95의 99.7~99.9%** — 모든 아키텍처 결정의 근거 | **실측** (E2E, 모델 2종) |
| 입력 토큰 중 프롬프트 오버헤드 비중 | **~85%** (820 tok 중 700) → 최대 절감 레버는 컨텍스트 캐싱 | **실측** (countTokens + E2E usage) |
| NER 추론 지연 (ONNX INT8, CPU) | **p50 8.3ms**, PER recall 100% — GPU 배제 근거 | **실측** (골든셋 100문장) |
| **번역 품질 (인명 재현율)** | **99.09% 실측** (링크 확정 인명, 시스템 결과 n=70) + chrF 41.52 기준선. **비열등 임계: 하락 0** — 런타임 게이트 오탐률 3.9% 선측정 | M3·M4에서 이 기준선과 비교 |
| 시스템 최대 처리량 / 병목 | 미측정 | M6 실측 |

계산 근거와 전체 가정: [`docs/cost-model.md`](docs/cost-model.md) — 가정을 바꾸면 재계산되는 파라미터화 모델.

## 왜 이 구조인가 (요약)

전체 지연의 99.7~99.9%(p95, 실측)가 통제 밖 외부 LLM API에 지배된다. 따라서:

- **비동기 큐 기반 처리** (Redis Streams) — 동기 스레드를 남의 API 지연에 묶지 않는다
- **NER을 비용 라우터로 재해석** — LLM 호출 전에 이미 실행된 난이도 분류기로 티어(T0/T1/T2) 결정
- **템플릿 슬롯 캐싱** — 의례적 정형문(`上曰`, `傳曰` 등)의 구조 일치 캐시로 LLM 호출 자체를 제거
- **비용을 SLI로, 예산을 서킷브레이커로** — 예산 소진율 기반 3단계 성능 저하
- **정확도를 게이트로** — 캐싱·라우팅은 품질을 깎아 비용을 버는 기능이다. KB로 확정된 인물이 번역문에 실제로 반영됐는지 런타임에 판정하고(추가 LLM 호출 0회), 비열등 임계를 통과한 경우에만 활성화한다. 인명 오역은 번역 오류가 아니라 사실 왜곡이기 때문

전체 설계·마일스톤·수용 기준: [`PROJECT_PLAN.md`](PROJECT_PLAN.md) · 진행 상황·재개 가이드: [`PROGRESS.md`](PROGRESS.md) · 결정 기록: [`docs/adr/`](docs/adr/)

## 아키텍처

```
클라이언트 → API 서버(Spring Boot) → Redis Streams 큐 → Worker(Spring Boot)
                                                          ├─ NER 서버 (Python + ONNX INT8, CPU)
                                                          ├─ KB 링킹 (in-memory 역색인, 2,690명)
                                                          ├─ 티어 라우팅 → Spring AI → Gemini
                                                          └─ PostgreSQL(결과·비용 원장) / Redis(캐시·예산)
                                     Micrometer → Prometheus → Grafana (비용 대시보드)
```
