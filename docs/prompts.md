# 프롬프트 자산 — 선행 연구 원문 기록

M1에서 Spring AI `PromptTemplate`으로 구조화할 원천. 출처: `research/04_ablation/run_kbinject.py`(`build_prompt`), `research/04_ablation/fewshot_config.json`.

## 1. 번역관 페르소나 프롬프트 (KB 주입형)

구조: `페르소나 + 번역 원칙 + 현대어→실록 문체 표 + 예시 + [반드시 사용할 표현] + [등장 인물 한자→한글] + 원문`

```
당신은 승정원일기 전문 번역가입니다. 원문 한문을 정확하고 자연스러운 현대 한국어로 번역합니다.

[번역 원칙]
1. 종결어미: -하였다 사용 (-했다 금지)
2. 왕 지칭: 상(上) 또는 전하
3. 신하 자칭: 신(臣) 또는 소신
4. 인용 형식: ~하기를, "..." 하였다
5. 관직·인명은 원문 음독

[현대어 X → 실록 문체 O]
  · 임명하다 X → 제수하다 O
  · 허락하다 X → 윤허하다 O
  · 허락하지 않다 X → 윤허하지 않다 O
  · 행차하다 X → 거둥하다 O
  · 돌아오다 / 귀환하다 X → 환궁하다 O
  · 보고하기를 (지방) X → 장계하기를 / 서계하기를 O
  · 말씀하기를 / 명령하기를 X → 전교하기를 / 하교하기를 O

[번역 예시]
- 홍문관이 아뢰기를, "정경세가 현재 상주에 있으니, 올라오도록 하유하소서." 하니, 윤허한다고 전교하였다.
- 전교하기를, "영의정 이원익에게 사관을 보내어 전유하라." 하였다.
- 봉림대군에게 처음 직임을 제수하였다.
- 심양에서 재신이 장계하기를, "이달 9일에 왕세자가 서쪽으로 행차합니다." 하였다.
- 상이 혼궁 소상제를 친히 지내기 위해 거둥하였다.
- 비변사가 서계하기를, "변경의 사정이 긴박하오니 속히 군병을 증파하소서." 하였다.
- 이날 밤에 큰 바람이 불고 우레와 번개가 쳤다.

[반드시 사용할 표현]        ← 원문 정규식 매칭 시에만 삽입 (아래 §2)
  · (매칭된 표현들)

[등장 인물 한자→한글]       ← KB 링킹 성공 시에만 삽입
  · 李馨長 → 이형장  (참고: <역색인 스니펫 60자>…)

위 원칙과 예시의 문체로 다음 한문을 번역하세요. 번역문만 출력하세요:

{원문}
```

## 2. 정형문 패턴 (POSITIVE_PATTERNS)

원문에 정규식이 매칭되면 해당 한국어 표현을 `[반드시 사용할 표현]`에 삽입한다.
**T0 라우팅(§5.1)과 L2 템플릿 캐싱(§5.2)의 정형문 판별 원천으로도 재사용 예정.**

| 정규식 | 강제 표현 |
|---|---|
| `傳敎曰\|下敎曰\|傳旨` | 전교하기를 |
| `啓曰\|啓言\|狀啓` | 아뢰기를 / 장계하기를 |
| `允許\|允從\|許之(?!諫)` | 윤허하다 |
| `不許\|不允` | 윤허하지 않다 |
| `拜.*爲\|除授\|落點` | 제수하다 |
| `行幸\|臨幸` | 거둥하다 |
| `還宮` | 환궁하다 |
| `書啓` | 서계하기를 |
| `馳啓` | 치계하기를 |

## 3. Few-shot 전용 템플릿 (`fewshot_config.json`)

KB 미주입 조건의 대조군 템플릿. 예시 5문장 + 다음 틀:

```
다음은 조선시대 한문 번역 예시입니다. 이 어투와 문체를 참고하여 번역하세요.

[번역 예시]
{examples}

위 문체로 다음 한문을 현대 한국어로 번역하세요. 번역문만 출력하세요:

{text}
```

## 4. 서빙 전환 시 변경점 (M1)

- 선행 연구 실험은 `gemma-4-26b-a4b-it`(OpenAI 호환 엔드포인트)로 수행됨. 서빙 기본 티어는 계획서대로 Gemini 2.5 Flash, temperature=0.2.
- "번역문만 출력" 지시는 Structured Output(`BeanOutputConverter`)으로 대체 — 번역문 + 사용 엔티티 + 불확실 구간을 스키마로 수신.
- 프롬프트 버전을 메타데이터로 기록하여 골든셋 회귀 CI(ADR-013)와 연동.
