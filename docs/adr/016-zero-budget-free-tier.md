# ADR-016: 운영 예산 0원 — 무료 티어 운영을 1급 제약으로 채택

- 상태: 승인 (사용자 결정, 2026-08-31)
- 날짜: 2026-08-31

## 배경

프로젝트 소유자가 운영 비용 0원을 명시했다 ("이 프로젝트에 쓸 돈 없다"). 첫 E2E에서 기존 키(결제 연동 프로젝트)가 월 지출 상한 429로 전 모델 차단됨을 확인했고(`docs/troubleshooting.md` §2), 선행 연구 자체도 무료 키 로테이션 + Gemma로 수행된 이력이 있다.

## 선택지

1. **Gemini API 무료 티어로 전면 전환** (결제 미연동 프로젝트 키)
2. 소액 유료 (실측용 $5~10만 지출)
3. 로컬 LLM (Ollama 등)으로 대체

## 결정

**선택지 1.** 이 제약은 시스템 설계를 약화시키지 않고 오히려 정당화한다:

- **일일 무료 quota(RPD)가 곧 예산 원장이다.** M5의 "예산 서킷브레이커"는 원화 대신 잔여 무료 요청 수를 SLI로 삼는다. 예산 소진율 70/85/100% 단계 저하 설계가 그대로 적용된다.
- **무료 티어의 낮은 RPM은 적응형 rate control(M2)을 선택이 아닌 필수로 만든다.** 429가 일상인 환경이 곧 우리 운영 환경이다.
- **유료 비용 모델은 counterfactual 헤드라인으로 유지한다**: "무료 quota로는 완역에 N년 → 유료 $746(실측 토큰 기반)이면 0.6일" — 비용/시간 트레이드오프가 포트폴리오의 핵심 표가 된다.
- 실험 설계 조정: 골든셋 검증·품질 곡선(M4)·회귀 CI(M6)는 일일 quota 안에서 층화 샘플로 규모를 설계하고, 인조 1년치 배치(M2)는 여러 날에 걸친 체크포인트 재개 실행으로 수행한다 — **체크포인트/재개 기능의 실전 데모가 공짜로 생긴다.**

운영 수칙:
- API 키는 결제 미연동 프로젝트에서 발급 (결제 연동 프로젝트 키는 유료 티어로 과금됨).
- 기본 모델은 무료 티어 제공 모델 중에서 선택하며 `GEMINI_MODEL` 환경변수로 주입 (새 키 발급 후 탐침으로 확정, 이 문서에 추기).
- 무료 티어 입력은 Google 제품 개선에 사용될 수 있음 — 본 프로젝트 입력은 공개 사료(승정원일기 원문)라 문제없다.

## 버린 대안과 그 이유

- **소액 유료(2)**: 사용자 제약 위반. 또한 "비용을 일급 지표로 다룬다"는 논지는 지출액이 아니라 설계로 증명하는 것이 맞다.
- **로컬 LLM(3)**: 16GB RAM에서 실용 품질의 한문→한국어 모델 서빙은 무리이고, 선행 연구와의 연속성(Gemini/Gemma 프롬프트 자산)도 잃는다. 외부 API 지연·rate limit이라는 이 프로젝트의 핵심 제약 자체가 사라져 아키텍처 당위가 무너진다.

## 재검토 조건

- 무료 quota 정책 변경으로 골든셋 300문장 평가조차 하루에 불가능해지면 (2) 최소 지출 또는 평가 규모 축소를 재검토.
