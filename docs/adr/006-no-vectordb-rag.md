# ADR-006: 벡터DB / RAG 어드바이저 배제

- 상태: 승인
- 날짜: 2026-08-31

## 배경

Spring AI는 VectorStore/RAG 어드바이저를 1급으로 지원하고, "AI 프로젝트 = RAG"가 통념이다. 본 프로젝트의 KB 검색에 이를 도입할지 결정해야 한다. 계획서 §7.

## 선택지

1. **결정론적 역색인 + 규칙 기반 중의성 해소 유지 (도입 안 함)**
2. 임베딩 기반 유사도 검색으로 대체/보강 (pgvector 등)

## 결정

**선택지 1 — 배제.** 본 KB 검색 대상은 자연어 문서가 아니라 **표층형이 유한한(9,403 키) 고유명사 사전**이다. 요구되는 것은 "李馨長이 어느 인물 ID인가"라는 정확 매칭 + 시간·관직 기반 중의성 해소이며, 임베딩 유사도는 여기에 **애초에 제거하려던 모호성(인명 경계, 동음이의)을 다시 도입**한다. 역색인 조회는 <1ms·비용 0·완전 재현 가능하다.

## 버린 대안과 그 이유

- (2) 임베딩 검색: 검색 대상이 비정형 텍스트이고 질의가 의미론적일 때 옳다. 본 시스템의 질의는 NER이 이미 뽑아낸 정확한 표층형이므로 의미 검색이 풀 문제가 없다. 유사도 top-k는 동명이인 해소에 오히려 비결정성을 추가하고, 벡터DB 운영 비용(인덱스 빌드, 갱신 동기화)만 얹는다.

## 재검토 조건

- KB 미등재 인물의 **별호·시호·자(字)** 등 표층형 변형 매칭이 실측상 주요 실패 원인으로 확인되고, 규칙 기반 확장으로 해소 불가할 때 한정적 보조 수단으로 재검토.
