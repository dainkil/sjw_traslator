# ADR-019: 품질 게이트와 비열등성 기준 (인명 재현율 하락 0)

- 상태: 승인 (M2.5-S5에서 구현)
- 날짜: 2026-09-01

## 배경

승정원일기에서 인명 오역은 번역 오류가 아니라 사실 왜곡이다 (선행 연구: 기존 모델 고유명사 정확도 8.3%).
M3(캐싱)·M4(하향 라우팅)는 비용을 깎는 축인데, 품질이 함께 깎였는지 시스템이 스스로 증명하지 못하면
"싸게 만들었다"는 주장만 남는다 (§5.4). M2까지는 LLM이 200이면 무조건 성공이었다.

## 선택지

1. **결정론 런타임 게이트 + 사전 고정 오프라인 비열등 임계**
2. LLM 심판(judge) 모델로 품질 평가
3. 오프라인 채점만 (런타임 무게이트)

## 결정

**선택지 1.** 두 층으로 구성:

**(1) 런타임 게이트** — KB로 링크가 확정된 인물의 한글명이 번역문에 등장하는지 검사.
LLM 추가 호출 0회. `quality_grade`(VERIFIED/DEGRADED/REJECTED)를 job에 기록, Micrometer로 분포 계측.

- REJECTED → **상위 티어(T1) 1회 승격 재호출** (M4 하향 라우팅의 대칭 — 품질 기반 상향).
  승격도 해당 모델 버킷 permit·원장 기록을 지키고, 승격 실패는 job을 죽이지 않는다 (1차 결과를 REJECTED로 반환).
- 재실패 시 검수 큐 = `quality_grade='REJECTED'` 행. 별도 큐 인프라를 만들지 않는다.
- **오탐 선측정 (측정 없이 켜지 않는다):** 골든셋 전문가 번역 181문장 대상 오탐률 **5.0% → 이형 표기 보정
  (성 생략 허용: 이름부 2자 이상 매칭) 후 3.9%** (`QualityGateGoldensetTest`, 회귀 상한 고정).
  잔여 오탐은 1자 표층형(珙·翼·衛)과 음차 변형(諿 집/즙) — 인명별 허용 목록의 후보로 기록.

**(2) 오프라인 비열등 게이트** — `eval/score_db.py`가 시스템 결과(Postgres)를 normalized_hash로
골든셋과 매칭해 채점. 임계는 **사전 고정**: chrF 기준선 대비 −2.0 이내, **링크 확정 인명 재현율 하락 0**(동등 요구).
위반 시 종료 코드 1 — CI 판정(M2.5-S8)의 입력. 기준선: n=70, chrF 41.52, 인명 재현율 0.9909 (flash-lite, 2026-09-01).

## 버린 대안과 그 이유

- **LLM 심판(2)**: 판정마다 quota를 태우고(무료 티어에서 자기부정), 심판 자체가 비결정이라 게이트가 흔들린다.
  결정론 신호(KB 확정 인명)를 이미 보유한 상태에서 확률 심판을 사는 것은 역선택.
- **오프라인만(3)**: 회귀는 잡아도 개별 오역은 그대로 나간다. 확정 인명 누락은 런타임에 잡을 수 있는
  결함인데 배치 리포트로 미루는 것은 게이트가 아니라 사후 보고다.

## 재검토 조건

- M3 캐시 재주입 결과가 DEGRADED로 유입되기 시작하면 표본 재검증 절차(§5.4)를 구체화.
- 오탐률이 배치 규모에서 T1 quota(RPD 20)를 위협하면: 1자 표층형 게이트 제외 또는 인명별 허용 목록 도입.
- 기준선 갱신은 모델·프롬프트 변경을 확정할 때만 (`--save-baseline`) — 무단 갱신은 게이트 무력화다.
